# Project memory

Index of this repository's memory vault. **One note per fact; this file is the only list.**

Open this folder in Obsidian (`.claude/memory/`). The `[[links]]` in the notes are already its syntax,
and the graph view is the point: a fact nobody links to is a fact nobody needed.

## Writing a note

Copy a file from `templates/` — one per memory type — or let Obsidian do it:
**Settings → Core plugins → Templates → Template folder location: `templates`**, then
*Insert template* in a new note. `{{title}}` and `{{date:YYYY-MM-DD}}` are filled in for you.

| Type | For |
|---|---|
| `project` | an ongoing constraint, goal or decision context the code does not state |
| `feedback` | guidance the team gave about how the work should be done, and why |
| `user` | who someone is — role, expertise, the way they want to be worked with |
| `reference` | where an external thing lives: dashboard, ticket board, runbook, spec |

The full discipline — what belongs here, what does not, and how to keep it honest — is in the
`project-memory` skill.
